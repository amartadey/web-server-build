Prerequisites

Everything you need before starting the server rebuild

On This Page

What You Need

Before starting the server rebuild process, make sure you have all the following requirements ready.

Required

Proxmox Server

A running Proxmox Virtual Environment server where you'll create the Ubuntu VM.

  • Proxmox VE 7.0 or later
  • Access to web interface
  • Sufficient resources available
Required

Domain Name

A domain name managed through Cloudflare for the tunnel setup.

  • Domain registered (e.g., webgraphicshub.com)
  • DNS managed by Cloudflare
  • Cloudflare account access
Required

System Resources

Minimum hardware resources for the virtual machine.

  • 8GB RAM (8192 MB)
  • 100GB Disk Space
  • 2-4 CPU Cores
Required

Ubuntu LTS ISO

Ubuntu Server Long Term Support version for HestiaCP compatibility.

  • Ubuntu 22.04 LTS (Recommended)
  • Ubuntu 20.04 LTS (Also supported)
  • Non-LTS versions NOT supported
Important: HestiaCP only supports LTS (Long Term Support) versions of Ubuntu. Always use an LTS version!
Required

Internet Connection

Stable internet connection for downloading packages and updates.

  • Works behind CGNAT
  • Dynamic IP is fine
  • No port forwarding needed
Optional

VS Code

Visual Studio Code for remote development (recommended for teams).

  • VS Code installed
  • Remote-SSH extension

Network Information

Understanding your network setup is important for the configuration process.

Network Details

Proxmox Network: 192.168.29.x
Server IP (Example): 192.168.29.15 (assigned via DHCP)
Gateway: 192.168.29.1 (your router)
DNS: Automatic (from router)
Note: Your actual IP address may be different. The server will get an IP automatically via DHCP during installation. Make sure to note it down!

Domains Configuration

You'll be setting up three subdomains for different services:

server.webgraphicshub.com

HestiaCP control panel for server management

SSL Enabled Country Restricted

dev.webgraphicshub.com

WordPress development site

SSL Enabled Public Access

email.webgraphicshub.com

Mailpit email testing interface

SSL Enabled Testing Only
Replace with your domain: Throughout this guide, replace webgraphicshub.com with your actual domain name.
