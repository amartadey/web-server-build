Cloudflare WAF Configuration

Restrict access to your server by country or other criteria using Cloudflare's Web Application Firewall.

Block All Countries Except India

  1. Go to Cloudflare Dashboard → Security → WAF
  2. Click "Create rule"
  3. Configure:
    • Field: Hostname
    • Operator: equals
    • Value: server.webgraphicshub.com
    • AND Country: is not in → India (IN)
    • Then: Block
  4. Click "Deploy"
Tip: You can create separate rules for each subdomain with different access restrictions.

Mailpit Password Protection

Add authentication to Mailpit using Cloudflare Access or Nginx Basic Auth.

Option 1: Cloudflare Access (Recommended)

  1. Go to Cloudflare Dashboard → Zero Trust → Access → Applications
  2. Click "Add an application" → "Self-hosted"
  3. Configure:
    • Application name: Mailpit
    • Subdomain: email
    • Domain: webgraphicshub.com
  4. Create policy to allow specific emails
  5. Save

VS Code for Multiple Developers

Set up individual developer accounts for better collaboration and tracking.

# Create developer accounts
sudo useradd -m -s /bin/bash dev1
sudo useradd -m -s /bin/bash dev2
sudo useradd -m -s /bin/bash dev3

# Set passwords
sudo passwd dev1
sudo passwd dev2
sudo passwd dev3

# Add to www-data group
sudo usermod -aG www-data dev1
sudo usermod -aG www-data dev2
sudo usermod -aG www-data dev3

# Give access to project folders
sudo setfacl -R -m g:www-data:rwx /home/dev/web/dev.webgraphicshub.com/public_html/
sudo setfacl -R -d -m g:www-data:rwx /home/dev/web/dev.webgraphicshub.com/public_html/
