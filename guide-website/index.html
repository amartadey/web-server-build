What You'll Build

A complete, production-ready development server accessible from anywhere

HestiaCP Control Panel

Free, powerful web hosting control panel for managing your server with an intuitive interface

  • Web server management
  • Database administration
  • FTP/SFTP access
  • SSL certificates

Cloudflare Tunnel

Bypass CGNAT and access your server from anywhere without port forwarding

  • No public IP needed
  • Automatic SSL/TLS
  • DDoS protection
  • Global CDN

WordPress Development

Quick WordPress installation with full development environment

  • One-click installation
  • Multiple sites support
  • VS Code integration
  • Team collaboration

Mailpit Email Testing

Catch and test all emails locally without sending to real addresses

  • Email preview
  • HTML/Text view
  • Attachment support
  • Search functionality

Docker Containers

Containerized services for easy management and deployment

  • Isolated environments
  • Easy updates
  • Resource efficient
  • Auto-restart

VS Code Remote

Edit files directly on the server with full VS Code functionality

  • SSH integration
  • IntelliSense support
  • Extensions enabled
  • Terminal access
